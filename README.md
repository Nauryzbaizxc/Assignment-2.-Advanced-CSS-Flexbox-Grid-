# Sound Stage — Web Project

Учебный проект по верстке многостраничного сайта для организации концертов и музыкальных мероприятий.

## Структура проекта
* `index.html` — Главная страница (Hero-секция, преимущества, ближайшие события)
* `services.html` — Услуги
* `about.html` — О компании
* `contact.html` — Контакты, форма бронирования, интерактивная карта, FAQ и галерея
* `css/style.css` — Основные стили проекта
* `css/responsive.css` — Адаптивные стили для мобильных устройств
* `images/` — Изображения и медиафайлы
