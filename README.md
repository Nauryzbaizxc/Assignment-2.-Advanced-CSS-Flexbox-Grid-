# Sound Stage — Assignment 5: DOM Manipulation & Events

Продолжение командного сайта Sound Stage (организация концертов и музыкальных мероприятий). Тема, дизайн и навигация сохранены из предыдущих заданий; добавлены интерактивные функции на JavaScript, манипуляции с DOM и обработка событий.

## Структура проекта

* index.html — Главная страница с интерактивными заданиями (Приветствие, Поиск, Список желаний)
* services.html — Каталог услуг и аренды оборудования
* about.html — Информация о компании, история и команда
* contact.html — Контактная форма, карта, галерея и интерактивный FAQ
* register.html — Форма регистрации слушателя с валидацией
* style.css & responsive.css — Основные стили и адаптивная верстка
* forms.css — Стилизация форм под тёмную тему и классы обратной связи
* interactive.js — Чистый JavaScript для Tasks 0–4 (манипуляции с DOM и события)
* forms.js — Валидация форм, классы .is-valid / .is-invalid, проверка совпадения паролей и сброс


## Как открыть

1. Откройте опубликованную ссылку (GitHub Pages или Netlify).
2. Или клонируйте репозиторий и откройте файл index.html в любом браузере.
