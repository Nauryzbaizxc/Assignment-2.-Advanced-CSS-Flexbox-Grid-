# Sound Stage — Assignment 5: Forms and Validation

Продолжение командного сайта Sound Stage (организация концертов и музыкальных мероприятий). Тема, дизайн и навигация сохранены из Assignment 2–3; добавлены формы и валидация.

## Структура проекта
* `index.html`, `services.html`, `about.html` — страницы из предыдущего задания (в меню добавлена ссылка «Регистрация»)
* `contact.html` — **Контактная форма** (Task 0–2), карта, галерея, FAQ
* `register.html` — **Форма регистрации** (Task 3)
* `style.css`, `responsive.css` — стили из предыдущего задания
* `forms.css` — адаптация Bootstrap-форм к тёмной теме сайта
* `forms.js` — валидация: Bootstrap-классы `.is-valid` / `.is-invalid`, проверка совпадения паролей, сброс формы
* Bootstrap 5.3.3 подключается по CDN (для просмотра нужен интернет)

## Как открыть
1. Откройте опубликованную ссылку (GitHub Pages / Netlify) или файл `index.html` локально.
2. Контактная форма: меню «Контакты» → `contact.html`. Регистрация: меню «Регистрация» → `register.html`.

## Какие HTML-атрибуты проверяют правила (Task 1)
| Правило | Атрибут |
| --- | --- |
| Поле обязательно | `required` |
| Имя не короче 2 символов | `minlength="2"` |
| Формат email | `type="email"` |
| Сообщение 10–500 символов | `minlength="10"` `maxlength="500"` |
| Пароль не короче 8 символов | `minlength="8"` |
| Страна выбрана | `required` на `<select>` с пустым первым `<option value="">` |
| Пароли совпадают | HTML5 не умеет — проверка в `forms.js` через `setCustomValidity()` |

Форма имеет `novalidate`, чтобы вместо всплывающих подсказок браузера показывать Bootstrap-сообщения. Правила при этом проверяет сам браузер через `checkValidity()`, поэтому обратная связь всегда соответствует реальному вводу.
